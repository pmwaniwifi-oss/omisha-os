# Omisha OS

Modular multi-tenant SaaS platform for Ubuntu Linux and Docker Compose.

Architecture: central control plane, per-customer Docker Compose stacks, selectable modules, and hybrid PostgreSQL isolation.

Development deployment target: Ubuntu Server VM on VMware Workstation.

**Status:** Repository initialized. Application source code is not yet uploaded. Do not expose the development control plane publicly or commit `.env`, tenant files, database volumes, or secrets.
